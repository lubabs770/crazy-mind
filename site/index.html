Installing an update

  1. Settings → System → System Updater → Check for Update, then Restart Now
  2. After the reboot, open the Mind app store and update Google Messages
  3. A messages update needs the latest system update installed first

If the download freezes: three-dot menu → Delete Update, restart the phone, then download again. Users who skipped several updates get one large download the first time, and smaller ones after.
